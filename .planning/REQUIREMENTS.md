# Requirements — Milestone v1.x

## v1.x Active / Deferred

Phases 8–14 requirements live in per-phase CONTEXT and PLAN files under `.planning/phases/`.

High-level themes:

- **Inference**: YOLO param expansion, hot-reload API (phase 8)
- **Stability**: reject rules, temporal stability spec alignment (phases 6, 9)
- **Sources**: camera types, viewport, coordinate mapping (phase 10)
- **Preprocess**: ROI crop stage, preprocessing controls (phase 11)
- **Vision**: classical CV pipeline overlays (phase 12)
- **Tracking**: primary target kinematics, tracker state machine (phase 13)
- **Config**: named profiles, web config API (phase 14)

## Out of Scope

- v2.0 classical-CV standalone module (`block_detection_v2`) — planning removed 2026-06-30
- Cloud API / auth
