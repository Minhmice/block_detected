### Grid specification

| Zone | Columns | Min height @ 1366×768 |
|------|---------|------------------------|
| TopStatusBar | full width | 56px |
| Sidebar | — | `100vh - 56px` |
| Main content area | 12-col | `100vh - 56px`, `overflow-y-auto` |
| Camera column | `col-span-12 lg:col-span-8` | flex column |
| CameraViewport | within camera column | `min-h-[360px]`, flex-1 |
| Classification + Pickup row | 2× equal cols inside camera column | `h-64` (256px) fixed |
| Parameters column | `col-span-12 lg:col-span-4` | `h-[calc(100vh-56px-32px)]` scroll |

**1366×768 target math:**
- Viewport: 1366×768
- Top bar: 56px → content height **712px**
- Main padding: 16px top + 16px bottom → inner **680px**
- Camera column ≈ `(1366 - 256 - 32) × 8/12 ≈ 726px` wide
- Params column ≈ `(1366 - 256 - 32) × 4/12 ≈ 363px` wide
- Classification row: 256px → camera viewport gets remaining **~424px** minimum

### Responsive breakpoints

| Breakpoint | Min width | Behavior |
|------------|-----------|----------|
| default | 0 | Sidebar hidden; single column; params below camera |
| `md` | 768px | Sidebar visible (`w-64`); connection stats in top bar |
| `lg` | 1024px | 8/4 column split active |
| `xl` | 1280px | Comfortable density; all overlay toggles visible |
| `2xl` | 1536px | Optional — no layout change; extra whitespace acceptable |

**1366×768 is the minimum supported desktop layout.** At exactly 1366px width, `lg` applies: sidebar + 8/4 split must fit without horizontal scroll. Params panel scrolls vertically; camera maintains aspect ratio with letterboxing.

## Connection States

Zustand slice: `connectionStatus: 'disconnected' | 'connecting' | 'connected' | 'error'`

| State | Top bar dot | Label copy | FPS / Latency | Stream | WebSocket |
|-------|-------------|------------|---------------|--------|-----------|
| `disconnected` | `#869397` (outline) | `DISCONNECTED` | `—` / `—` | Placeholder | Not connected |
| `connecting` | `#fbbf24` pulse | `CONNECTING…` | `—` / `—` | Loading spinner | Handshake |
| `connected` | `#4edea3` solid | `CONNECTED` | Live values | MJPEG active | Receiving telemetry |
| `error` | `#ffb4ab` solid | `CONNECTION ERROR` | `—` / `—` | Error overlay | Reconnect backoff |

**Reconnect UX:** `lib/ws.ts` auto-reconnect; each transition appends one line to `LogTerminal`:
- `> WS connected`
- `> WS disconnected — reconnecting in {n}s`
- `> WS error: {message}`

**Mock mode indicator:** When backend reports mock camera, show badge in `TopStatusBar`: `MOCK_MODE` — `outline-variant` border, `on-surface-variant` text, 10px label-caps. Do not use success green.

**Health poll:** `GET /health` every 30s; failure moves to `error` if WS also down.

### CameraViewport

**Purpose:** MJPEG stream display + overlay mount point.

**Structure:**
- Panel header: `CAM_FEED_01` label + overlay toggle chips (see VisionOverlay)
- Body: `relative flex-1 bg-black overflow-hidden min-h-[360px]`
- Footer: `Snapshot` (client capture), `Save Failed Frame` → `POST /api/dataset/save-frame`

**Stream implementation:**
```tsx
<img
  src={process.env.NEXT_PUBLIC_STREAM_URL}
  alt="Camera feed"
  className="max-w-full max-h-full object-contain"
  ref={imgRef}  // supplies naturalWidth/Height to VisionOverlay
/>
```

**Letterboxing:** Stream centered; black bars on sides or top/bottom. Overlay canvas matches **rendered image rect**, not panel rect.

**Empty / error states:**
- No stream URL: centered label-caps `NO STREAM — CHECK NEXT_PUBLIC_STREAM_URL`
- Stream error: `CAMERA UNAVAILABLE` + retry button
- Mock mode: optional static placeholder image with `MOCK FEED` watermark (10px, opacity 50%)

**Badges (pointer-events-none):**
- Top-left: pickup x/y mm when valid (`data-md`, primary, bg-surface/50)
- Top-right: `VALID` (secondary) or `INVALID` (error) or `{rejectReason}` (warning, truncated)

**Hover:** Bottom-right mouse px readout (`opacity-0 group-hover:opacity-100`) — optional v1 if trivial.

### VisionOverlay

**Purpose:** Canvas layer aligned to MJPEG image; draws geometry from latest WebSocket `DetectionResult`.

**Implementation:** HTML `<canvas>` absolutely positioned over image; `pointer-events-none`; `z-10`. Resize on `ResizeObserver` + image `onLoad`.

**Coordinate mapping:**
```
scaleX = renderedWidth / nativeWidth   // expect 640 native
scaleY = renderedHeight / nativeHeight // expect 480 native
screenX = offsetX + pxX * scaleX
screenY = offsetY + pxY * scaleY
```
`offsetX/Y` = letterbox inset within container.

**Wire format (camelCase JSON):** `cornersPx.tl|tr|br|bl`, `centerPx`, `angleDeg`, `bboxPx`, `pickupPoseMm`, `blockId`, `confidence`, `valid`, `rejectReason`.

**Toggle chips (header):** Each toggles a boolean in Zustand `overlayFlags`:

| Chip | Default | Layer |
|------|---------|-------|
| Show Contours | off | Future — hide in v1 unless backend sends contour path |
| Square Corners | on | Corner markers + connecting bbox |
| Warped Face | off | Picture-in-picture in ClassificationPanel instead |
| Center Point | on | Center dot + axis cross |
| Angle Arrow | on | Yellow arrow from center |
| Pickup Pose | on | Text label near center |

Active chip: `border-primary text-primary`; inactive: `border-outline-variant text-on-surface-variant`.

**Drawing rules:** See [Overlay Drawing Rules](#overlay-drawing-rules).

**No detection:** When `valid === false` or missing geometry, draw crosshair grid only; hide block graphics.

### DetectionControls

**Purpose:** Right-column parameter panel; all sliders debounced to backend.

**Container:** `.panel`, `p-16`, full column height, `overflow-y-auto`, header `DETECTION_PARAMETERS`.

**Controls (from `vision.example.json` + reference HTML):**

| Control | Type | Range / options | Zustand key |
|---------|------|-----------------|-------------|
| INPUT_RESOLUTION | select | 640×480 (locked default), 320×240 | `resolution` |
| BLUR_KERNEL | slider + number | 1–15, step 2 | `blurKernel` |
| CANNY_THRESH_MIN | slider + number | 0–255 | `cannyMin` |
| CANNY_THRESH_MAX | slider + number | 0–255 | `cannyMax` |
| CONTOUR_AREA_MIN | slider + number | 0–10000 | `contourAreaMin` |
| CONTOUR_AREA_MAX | slider + number | 0–100000 | `contourAreaMax` |
| ASPECT_RATIO_TOLERANCE | slider + number | 0–1, step 0.05 | `aspectTolerance` |
| CONFIDENCE_THRESH | slider + number | 0–100 (display %), send 0–1 | `confidenceThresh` |
| THRESHOLD_MODE | select | Canny, Adaptive, HSV | `thresholdMode` |
| Reject if angle error high | toggle | boolean | `rejectAngleError` |
| Reject if corner not complete | toggle | boolean | `rejectIncompleteCorners` |

**Slider styling:** Track `h-0.5 bg-outline-variant`, accent `primary`, machined rectangular thumb via Tailwind `appearance-none` + custom CSS.

**Input styling (`.data-input`):** `bg-surface-container-highest border border-outline-variant`, focus `border-primary`, font data-md.

**Debounce:** Update Zustand immediately on input; POST `/api/detection/params` after **400ms** idle (discretion range 300–500ms).

**Footer:** `RESET DEFAULTS` — restores defaults from `vision.example.json` values, POST params.

**Section dividers:** `border-t border-outline-variant` between slider groups (pt-8).

## Overlay Drawing Rules

All strokes use integer-rounded coordinates after scale transform. Clear canvas each frame before redraw.

### Layer 0 — Fixed grid (always when feed visible)

- 24×24px grid, color `#80808012`
- Center crosshair: horizontal + vertical `primary` at 30% opacity, 1px
- Center ring: 32×32px circle, `border-primary/50`, 1px, centered on image center (320, 240) — not block center

### Layer 1 — Bounding box (toggle: Square Corners)

- Stroke: **2px** `#4edea3` (secondary/success)
- Draw `bboxPx` if present; else quadrilateral connecting `cornersPx` tl→tr→br→bl→tl
- Label above top-left: `ID:0{n}` + `{confidence*100:.1f}%` — bg secondary, text on-secondary, 10px data-md

### Layer 2 — Corner markers (toggle: Square Corners)

- Four squares **8×8px** filled `#4cd7f6` (primary), centered on each corner point
- Optional 1px primary outline on outer bbox corners (reference style)

### Layer 3 — Center point (toggle: Center Point)

- Dot: 8×8px circle filled primary at `centerPx`
- Axis cross through center: X axis `#ef4444` 32px length; Y axis `#22c55e` 32px length; 1px — matches reference red/green

### Layer 4 — Angle arrow (toggle: Angle Arrow)

- From `centerPx`, length **48px**, 2px stroke `#fbbf24` (warning)
- Direction: `angleDeg` counter-clockwise from +X axis (match backend/image convention)
- Arrowhead: 8px chevron at tip, same color

### Layer 5 — Pickup pose text (toggle: Pickup Pose)

- Position: 8px offset right of center dot
- Text (data-md 10px, primary):
  ```
  X:{pickupPoseMm.xMm} Y:{pickupPoseMm.yMm} θ:{pickupPoseMm.thetaDeg}°
  ```
- Hide when `pickupPoseMm` null

### Invalid / rejected detection

- Do not draw layers 1–5
- Optional: dashed outline-variant bbox if partial corners exist (debug only, off by default)

### Performance

- RequestAnimationFrame sync with WS message rate; max 30 redraws/s
- Single canvas context; avoid shadowBlur
