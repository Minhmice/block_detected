  <files>src/block_detected/runtime/api/routes/stream.py, src/block_detected/runtime/api/routes/__init__.py</files>
  <action>
    Implement MJPEG streaming (per CONTEXT D-MJPEG: prefer MJPEG over WebSocket for `<img src>` compatibility):

    - `router = APIRouter(tags=["stream"])`
    - `GET /stream` async generator `mjpeg_frames(service: EngineService)`:
      - Loop while client connected: read `jpeg = service.get_latest_jpeg()`; if jpeg, yield boundary frame:
        ```
        --frame\r\nContent-Type: image/jpeg\r\nContent-Length: {len}\r\n\r\n{bytes}\r\n
        ```
      - If no frame yet, yield nothing but sleep ~33ms (≈30fps poll); do not spin CPU.
      - On `asyncio.CancelledError`, exit cleanly.
    - Return `StreamingResponse(mjpeg_frames(...), media_type="multipart/x-mixed-replace; boundary=frame")`.
    - Inject `EngineService` via `Depends(get_engine_service)` (import dependency from `apps.web.server` or move `get_engine_service` to `runtime/api/deps.py` if circular — prefer small `runtime/api/deps.py` with `get_engine_service` to keep routes importable in tests).

    Export routers from `routes/__init__.py`.
