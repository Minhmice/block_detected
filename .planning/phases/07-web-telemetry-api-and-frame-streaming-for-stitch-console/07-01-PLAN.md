  <name>Task 1: EngineService thread-safe frame loop</name>
  <files>src/block_detected/runtime/api/__init__.py, src/block_detected/runtime/api/service.py</files>
  <action>
    Create `EngineService` in `runtime/api/service.py` (per CONTEXT architecture — api layer wraps runtime, no detection duplication):

    - Constructor accepts `AppConfig` (load via `config_store.load_config()` at app startup, not in service).
    - State: `_lock`, `_thread`, `_stop_event`, `_engine: WebcamEngine | None`, `_latest_jpeg: bytes | None`, `_latest_status: RuntimeStatus | None`, `_running: bool`, `_last_error: str | None`.
    - `start()` → call `WebcamEngine.try_create`, then `try_start`; spawn daemon `threading.Thread` target `_loop`. On failure set `_last_error` and return `(ok, message)`.
    - `_loop` → while not stopped: `processed = engine.process_frame()`; if None break; under lock encode `processed.annotated` to JPEG via `cv2.imencode(".jpg", ..., [IMWRITE_JPEG_QUALITY, 80])`, store bytes + `processed.status`; small sleep (~1ms) like GUI.
    - `stop()` → set stop event, join thread (timeout 5s), `engine.shutdown(destroy_cv_windows=False)`, clear latest frame.
    - `switch_model()` / `switch_camera()` → if engine running, call engine methods under lock (same thread as loop — use `_pending_switch_model` / `_pending_switch_camera` flags applied at top of loop iteration, mirroring GUI `_apply_pending` pattern; do NOT call OpenCV capture ops from HTTP thread directly).
    - Read-only accessors: `is_running`, `last_error`, `get_latest_jpeg() -> bytes | None`, `get_status() -> RuntimeStatus | None`.
    - Export from `runtime/api/__init__.py`: `EngineService`.

    Do NOT import FastAPI or uvicorn in `runtime/api/` (dependency rule: api → runtime only).
  </action>
  <verify>
    <automated>python -c "from block_detected.runtime.api.service import EngineService; from block_detected.runtime.config_schema import AppConfig; s=EngineService(AppConfig.defaults()); assert hasattr(s,'start') and hasattr(s,'get_latest_jpeg')"</automated>
  </verify>
