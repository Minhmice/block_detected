<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller frame -> `detect_block(frame)` | Arbitrary Python objects can be passed by integrators before camera validation exists. |
| package imports -> external integrators | Root and package import paths must resolve to the same contract objects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Denial of Service | `detect_block(frame)` | high | mitigate | Accept arbitrary objects without indexing except guarded mapping reads; return validated no-detection rather than raising for unsupported input. |
| T-01-05 | Tampering | pipeline return construction | high | mitigate | Call `validate_detection_result()` on every return path and do not duplicate contract validation in pipeline code. |
| T-01-06 | Spoofing | synthetic success sentinel | medium | mitigate | Restrict synthetic success to an explicit test sentinel key/value; ordinary non-null frames must not receive sample success geometry. |
| T-01-07 | Information Disclosure | debug metadata | low | accept | Only copy a string `frame_id`; do not serialize frame contents, paths, or object reprs into debug output. |
</threat_model>
