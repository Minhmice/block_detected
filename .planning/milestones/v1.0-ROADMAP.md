# Milestone v1.0: Hex Detector MVP

**Status:** ✅ SHIPPED 2026-07-03
**Phases:** 1–2
**Total Plans:** 3

## Overview

CPU-only OpenCV library that extracts hex/rectangle block-face geometry (points A–F) from YOLO tracking bboxes, plus an interactive dataset debugger for tuning and diagnosis. Greenfield module independent of legacy `block_detected`.

## Milestone Summary

**Key Decisions:**

- Front-first architecture: rectangle before hex; never synthesize C/D
- Bounded candidates in config to prevent combinatorial CPU explosion
- Fresh HexDetector per dataset image to prevent hold/EMA leakage
- Observational instrumentation only in debugger phase

**Issues Resolved:**

- Old 7-line combinatorial bottleneck replaced with independent front/right candidate picking
- Phase 2 verification gaps (uncommitted test mods) closed in re-verification

**Issues Deferred:**

- Pi 5 on-device CPU/memory profiling (human verification)
- OpenCV HighGUI keyboard behavior across backends (human verification)

**Technical Debt Incurred:**

- Planning artifacts drifted during pivot — reconciled at milestone close
- No ground-truth accuracy metrics or video-frame temporal tracking yet
