## Validated (shipped v1.0)

- [x] R-01: Front-first rectangle/hex detection — `src/hex_detector/` with bounded candidates and stable `RejectReason` codes
- [x] R-02: Guarded one-tick-per-frame hold-last-good with multiplicative score decay
- [x] R-03: Basic/verbose debug rendering defaults to winner-only geometry
- [x] R-04: `scripts/debug_hex_dataset.py` — YOLO → hex_detector per image, keyboard navigation
- [x] R-05: Per-stage timings (hough, filter, group, merge) and Canny edges in verbose payload
- [x] R-06: `debug_config.json` whitelist reload via R key

## Out of Scope

- Train / fine-tune YOLO — model đã có
- YOLO Pose — chỉ dùng bbox + track_id
- Sửa YOLO tracker hiện tại — hex_detector là layer độc lập
- GPU / CUDA — CPU-only cho Pi 5
- FastAPI / web telemetry — MVP local
- Complex GUI, video tracking, ground-truth annotation, HTML reports
